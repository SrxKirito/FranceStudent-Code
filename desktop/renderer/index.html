Paramètres
Modèle
Utilisé aux prochains démarrages. Pour changer le modèle de la conversation en cours, clique sur le nom du modèle dans la barre d'état (/model).
Écritures de fichiers
« Toujours autoriser » reste actif aux prochains démarrages (équivalent de /auto always).
Commandes
« Toujours autoriser » reste actif aux prochains démarrages (badge d'avertissement dans la barre d'état).
Les commandes interdites (rm, shells, sudo, git push…) restent toujours bloquées.
Import et mises à jour
Copie AGENTS.md et les prompts de ~/.codex en skills utilisateur FranceStudent (les existants ne sont pas écrasés).
Accès web
Le modèle peut chercher sur Internet pour répondre (équivalent de /web on dans le CLI).
Skills et MCP
En mode manuel, cite le skill ou le serveur MCP dans ta demande (ex. « utilise le skill pdf », « @rea »). Équivalent de /extensions auto|manual dans le CLI.

Marketplace SkillsMP
Sans clé, SkillsMP limite à 50 recherches par jour. Clé gratuite sur skillsmp.com/developers. Elle est enregistrée dans settings.json et prime sur la variable d'environnement.
Indexation du projet
Champ vide = valeur par défaut. Lire plus de fichiers rend l'indexation plus lente et plus coûteuse en tokens. Les réglages sont globaux et s'appliquent au prochain /index ou à la prochaine ouverture de projet.
